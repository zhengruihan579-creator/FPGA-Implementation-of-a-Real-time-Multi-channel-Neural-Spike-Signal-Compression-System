# Dataset Acquisition

The Python scripts read raw datasets from a data directory. Either place the files
in this `data/` directory (one level above `software/`), or set the environment
variable `SPIKE_DATA_DIR` to point to a directory containing them.

## 1. Quiroga simulated dataset (single-channel evaluation)

- **Source:** R. Q. Quiroga, Z. Nadasdy, and Y. Ben-Shaul, "Unsupervised spike
  detection and sorting with wavelets and superparamagnetic clustering," *Neural
  Computation*, 2004.
- **Download:** https://figshare.le.ac.uk/articles/dataset/Simulated_dataset/11897595
- **Required files:** `C_Easy1_noise005.mat`, `C_Easy2_noise005.mat`,
  `C_Difficult1_noise005.mat`, `C_Difficult2_noise005.mat` (and optionally the
  other noise-level variants referenced by the scripts).
- Each file provides the raw waveform, the true spike times, and the cluster
  labels (k = 3) used as ground truth.

## 2. Cortex Lab Neuropixels 1.0 dataset (multi-channel evaluation)

- **Source:** publicly available extracellular recording from a Neuropixels 1.0
  probe (IMEC), 384 channels per shank, sampled at 30 kHz, provided by Cortex Lab.
- Each channel provides ~60 s of continuous recording. Ground-truth spike times
  and cluster labels for the multi-channel F1 evaluation are produced with
  Kilosort4 (`run_kilosort4_low_thresh.py`).
- If the exact preprocessed file is not redistributed here due to size, please
  contact the corresponding author for the preprocessed recording, or run
  `run_kilosort4_low_thresh.py` on your own Neuropixels recording.

## Notes

- Large binary files (`.npz`/`.bin`) are intentionally **not** included in this
  repository to keep it lightweight. They are regenerated by running the scripts.
- The single-channel scripts use the Quiroga `.mat` files; the multi-channel
  scripts expect the preprocessed Neuropixels data in `transfer/kilosort4_full/`
  (see `run_kilosort4_low_thresh.py` and `SD_CS_MultiChannel_Sim.py` for the
  expected layout).
